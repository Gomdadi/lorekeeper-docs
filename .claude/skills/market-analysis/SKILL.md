# Market Analysis Skill

## 워크플로우

1. `.claude/docs/references.md` 를 읽어 서비스 도메인·핵심 기능·차별화 논리를 파악한다.
2. `references/example.md` 를 읽어 출력 구조(섹션 구성, 표 형식, 규칙)를 확인한다.
3. 웹 검색으로 관련 시장 규모·성장률·경쟁 서비스 최신 수치를 확보한다.
4. 파악한 도메인 컨텍스트와 검색 데이터를 결합해 시장 분석 섹션을 **두 가지 형식**으로 작성한다.
   - **마크다운 버전**: `references/examples.md`의 구조 템플릿을 따른 섹션·표·글머리표 형식
   - **Word 원문 버전**: 표·기호 없이 문단 단위 산문으로 작성한 텍스트 (Word에 바로 붙여넣기 가능)

## 작성 기준

- **도메인 컨텍스트 우선**: `.claude/docs/references.md`의 핵심 논리(설득 포인트, 차별화 근거)를 시장 분석 서술에 적극 반영한다.
- **수치 근거 확보**: 시장 규모·성장률 등 정량 지표는 웹 검색으로 최신 자료를 수집하고 출처를 반드시 표기한다. 찾지 못한 수치는 `> 가정:` 블록으로 명시한다.
- **출처 URL 필수**: 출처 표의 모든 행에는 웹 검색에서 확인한 URL을 마크다운 링크 형식(`[링크](URL)`)으로 반드시 삽입한다. URL을 확인하지 못한 항목은 셀을 `-`로 표기하고 `> 가정:` 블록으로 별도 명시한다. 나무위키·Wikipedia 등 불특정 다수 편집 가능 문서는 조사 참고용으로만 사용하고 출처 표에 등재하지 않는다.
- **경쟁사 분석**: references.md에서 언급된 경쟁 서비스 유형을 기반으로 실제 서비스를 조사해 표로 정리한다.
- **차별화 축 도출**: references.md의 As-Is/To-Be/The Gap 구조를 참고해 차별화 요소의 축을 설정한다.
- **기존 방식과의 차별성·혁신요소**: 기존 시장·서비스 대비 본 서비스가 해결하는 문제와 혁신 포인트를 별도 섹션으로 서술한다. references.md의 As-Is(문제인식)와 The Gap을 근거로 작성하며, "기존에는 X였으나, 본 서비스는 Y를 통해 Z를 실현한다"는 구조로 서술한다.
- **개발 타당성**: 시장 규모·성장률 수치와 경쟁사 분석 결과를 근거로 본 프로젝트의 개발 필요성과 시장 진입 가능성을 2~3문장으로 요약한다.
