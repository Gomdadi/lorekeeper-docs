# Market Analysis Skill

## 워크플로우

1. `.claude/docs/references.md` 를 읽어 서비스 도메인·핵심 기능·차별화 논리를 파악한다.
2. `references/example.md` 를 읽어 출력 구조(섹션 구성, 표 형식, 규칙)를 확인한다.
3. 웹 검색으로 관련 시장 규모·성장률·경쟁 서비스 최신 수치를 확보한다.
4. 파악한 도메인 컨텍스트와 검색 데이터를 결합해 시장 분석 섹션을 **두 가지 형식**으로 작성한다.
   - **마크다운 버전**: `references/examples.md`의 구조 템플릿을 따른 섹션·표·글머리표 형식
   - **Word 원문 버전**: 표·기호 없이 문단 단위 산문으로 작성한 텍스트 (Word에 바로 붙여넣기 가능)
5. 시장 지표를 뒷받침하는 이미지를 웹 검색으로 찾아 다운로드하고, md 파일에 삽입 위치를 표시한다. (아래 **이미지 처리 워크플로우** 참고)

## 작성 기준

- **도메인 컨텍스트 우선**: `.claude/docs/references.md`의 핵심 논리(설득 포인트, 차별화 근거)를 시장 분석 서술에 적극 반영한다.
- **수치 근거 확보**: 시장 규모·성장률 등 정량 지표는 웹 검색으로 최신 자료를 수집하고 출처를 반드시 표기한다. 찾지 못한 수치는 `> 가정:` 블록으로 명시한다.
- **출처 URL 필수**: 출처 표의 모든 행에는 웹 검색에서 확인한 URL을 마크다운 링크 형식(`[링크](URL)`)으로 반드시 삽입한다. URL을 확인하지 못한 항목은 셀을 `-`로 표기하고 `> 가정:` 블록으로 별도 명시한다. 나무위키·Wikipedia 등 불특정 다수 편집 가능 문서는 조사 참고용으로만 사용하고 출처 표에 등재하지 않는다.
- **경쟁사 분석**: references.md에서 언급된 경쟁 서비스 유형을 기반으로 실제 서비스를 조사해 표로 정리한다.
- **차별화 축 도출**: references.md의 As-Is/To-Be/The Gap 구조를 참고해 차별화 요소의 축을 설정한다.
- **기존 방식과의 차별성·혁신요소**: 기존 시장·서비스 대비 본 서비스가 해결하는 문제와 혁신 포인트를 별도 섹션으로 서술한다. references.md의 As-Is(문제인식)와 The Gap을 근거로 작성하며, "기존에는 X였으나, 본 서비스는 Y를 통해 Z를 실현한다"는 구조로 서술한다.
- **개발 타당성**: 시장 규모·성장률 수치와 경쟁사 분석 결과를 근거로 본 프로젝트의 개발 필요성과 시장 진입 가능성을 2~3문장으로 요약한다.
- **프로젝트 소개 미포함**: 서비스 개요·기능 설명·문제 배경 등 프로젝트 소개에 해당하는 내용은 시장 분석 섹션(마크다운·Word 버전 모두)에 작성하지 않는다. 해당 내용은 별도 프로젝트 소개 항목에서 다룬다.

## 이미지 처리 워크플로우

시장 동향 수치를 시각적으로 보강하는 차트·그래프 이미지를 확보한다.

### 탐색 우선순위

1. **공공기관 자료**: 한국출판문화산업진흥원(KPIPA), 문화체육관광부, 통계청 등 공공기관 보도자료·보고서의 차트 이미지 (공공저작물로 출처 표기 시 자유 이용 가능)
2. **언론 인포그래픽**: 보도자료를 인용한 신문·매체의 차트 이미지 (출처 표기 조건)
3. **글로벌 리서치 기관 프리뷰**: Statista, Valuates Reports 등의 무료 공개 미리보기 차트

### 다운로드 및 저장 규칙

- 저장 경로: `docs/images/` 폴더 생성 후 저장
- 파일명: 내용을 명확히 반영하는 영문 소문자 케밥 케이스 (예: `korean-webnovel-market-2024.png`)
- 다운로드 명령: `curl -L -o docs/images/<파일명> "<이미지URL>"`
- 다운로드 실패(403, 404 등) 시 다른 URL을 시도하고, 모든 시도가 실패하면 위치 플레이스홀더만 삽입

### md 파일 삽입 형식

이미지가 다운로드된 경우:
```markdown
![설명 텍스트](images/파일명.png)
*출처: 기관명, 보고서명, 연도*
```

다운로드 실패 시 플레이스홀더:
```markdown
<!-- 이미지 삽입 필요: 설명 (출처: URL) -->
```

### Word 원문 버전 이미지 표시 형식

Word 원문 버전은 산문 텍스트이므로 마크다운 문법 대신 아래 형식으로 이미지 삽입 위치를 표시한다.
해당 줄은 Word에 붙여넣은 후 실제 이미지로 교체할 수 있도록 명확하게 구분한다.

```
[이미지 삽입: 설명 — 파일명: images/파일명.png / 출처: 기관명, 연도]
```

예시:
```
[이미지 삽입: 국내 웹소설 시장 규모 성장 그래프 — 파일명: images/korean-webnovel-market-2024.png / 출처: 한국출판문화산업진흥원, 2025]
```

### 적합한 이미지 유형

| 삽입 위치 | 권장 이미지 유형 |
|-----------|----------------|
| 시장 동향 섹션 | 국내 웹소설 시장 규모 성장 그래프, AI 글쓰기 시장 성장 차트 |
| 경쟁 서비스 섹션 | 경쟁사 서비스 화면 캡처 (단, 저작권 확인 필요) |
| 개발 타당성 섹션 | 유료 결제 비율 등 사용자 통계 인포그래픽 |
