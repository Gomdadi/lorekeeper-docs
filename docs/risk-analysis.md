# 예상문제 및 해결방법

| 구분 | 문제점 | 해결방안 |
|------|--------|----------|
| 개발 측면 | 세계관 분석 시스템은 여러 핵심 기능이 맞물려 작동하는 구조로, 하나가 제대로 구현되지 않으면 전체 서비스 품질에 연쇄 영향을 미침 | 핵심 기능을 개발 초반에 먼저 시험 구현해 문제를 조기에 발견하고, 단계별로 기능을 확장해 리스크를 분산 |
| 프로젝트 관리 측면 | 핵심 기능 시험 구현이 지연될 경우 전체 일정이 연달아 밀리며, 새로운 기술 학습 부담이 개발 속도를 늦출 수 있음 | 핵심 기능 검증을 개발 초반에 우선 배치해 병목을 조기 식별하고, 막히면 멘토 지원 요청 또는 대안 기술로 신속 전환 |
| 상용화 측면 | 장편 연재 작가라는 특수한 사용자층 특성상 초기 인지도 확보와 사용자 모집이 어려움 | 웹소설 커뮤니티와 연재 플랫폼 채널에서 무료 기능으로 베타 테스터를 모집해 초기 사용자 풀 확보 |
| 상용화 측면 | AI 분석 기능 사용량에 비례해 외부 AI 서비스 이용 비용이 증가해 수익성 확보가 어려울 수 있음 | 불필요한 AI 호출을 최소화하고, 고부하 기능은 유료로 전환해 비용 회수 |
| 기타 | 미공개 원고 업로드 시 저작권·유출 문제 발생 가능성 | 업로드 원고가 AI 학습에 사용되지 않도록 정책 적용, 분석 완료 후 원본 즉시 삭제, 온보딩 시 데이터 처리 방침 명시 |
| 기타 | 외부 AI 서비스의 정책 변경·중단 시 핵심 기능 전체가 멈출 위험 | 복수의 AI 서비스를 연동해 장애 시 즉시 대응하고, 장기적으로 자체 AI 운영을 검토해 외부 의존도를 단계적으로 축소 |
