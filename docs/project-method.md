# 수행방법

## 추진방식

### 개발 측면

1. 다차원 세계관 해체 및 지식 그래프 구축 (Onboarding & Ingestion): 작가가 기존 연재 원고를 업로드하면 서버가 이를 화 단위로 파싱하고 LangGraph 기반 LLM 분석 파이프라인을 트리거한다. Claude LLM(Sonnet 4.6 또는 Opus 4.6)이 등장인물·사건·사물을 식별하고 인과·소속·상태변화 등 관계를 추론한 뒤, Graph DB에 저장할 Cypher 쿼리를 동적으로 생성한다. 원문은 청크 단위로 임베딩해 Vector DB에 병행 저장하여, Graph 탐색만으로 컨텍스트가 부족할 경우 원문 구절을 보조적으로 retrieve하는 하이브리드 GraphRAG 방식을 구축한다. 분석 완료 후 구축된 지식 그래프를 작가에게 시각화해 제공하며, 무협·판타지·로맨스 등 장르 특화 템플릿을 통해 향후 전개될 설정을 작가가 직접 추가 등록할 수 있는 위키 환경도 지원한다.

2. RAG 기반 설정 충돌 사전 감지 및 스마트 집필 보조 (Drafting): 작가가 신규 회차를 업로드하면 설정 오류 검증 파이프라인이 실행된다. LLM이 신규 회차에서 주요 인물·사건·사물을 추출하고 Graph DB에 반복 쿼리를 수행해 관련 컨텍스트를 충분히 확보한 뒤, 기존 세계관과 대조해 설정 충돌 여부를 판단한다. 빠르고 가벼운 요약·키워드 검색은 Elasticsearch를 통해 즉시 처리하고, 복합 인과관계 데이터는 백엔드에서 조합하여 LLM에 전달하는 하이브리드 검색 구조로 속도와 정확도를 동시에 확보한다. 충돌 감지 시 신규 회차 수정안과 기존 원고 수정안을 함께 제시하여 작가가 선택할 수 있도록 한다. 배포 이후 정탐/오탐 피드백 데이터를 수집해 프롬프트와 Graph 탐색 로직을 반복 개선한다.

3. 레트콘(Retcon) 파급 효과 비동기 역추적 (Ripple Effect Tracking): 작가가 레트콘을 선택할 경우 Kafka 기반 비동기 이벤트 파이프라인을 통해 변경된 설정이 과거 에피소드 전체에 미치는 파급 효과를 역추적한다. 무거운 역추적 연산 부하를 동기식으로 처리할 경우 시스템이 불안정해질 수 있으므로 EDA(Event-Driven Architecture) 구조로 분리해 비동기 분산 처리하며, 연산 완료 후 수정이 필요한 과거 에피소드 및 대사 목록을 상세 리포트 형태로 자동 생성해 작가에게 제안한다.

4. 핵심 구현 방식: 원고 업로드 시 LangGraph·Claude LLM 기반 파이프라인이 인물·사건·관계를 추론해 Graph DB와 Vector DB에 이중 저장하고, 신규 회차 집필 시 Elasticsearch와 GraphRAG를 결합한 하이브리드 검색으로 설정 충돌을 사전 감지한다. 레트콘 발생 시에는 Kafka EDA로 파급 효과를 비동기 역추적해 수정 대상 에피소드를 리포트로 제공한다.

---

### 비개발 측면

1. 유저 확보 방안: 웹소설 작가 커뮤니티(글담 등)와 카카오페이지·네이버시리즈 연재 작가 채널을 중심으로 베타 테스터를 모집한다. MVP 출시 초기에는 기본 세계관 구축 및 설정 충돌 감지 기능을 무료로 제공해 초기 사용자 풀을 확보한다.

2. 사용자 피드백 수집: 베타 배포 후 앱 내 피드백 폼을 통해 의견을 수집하고, 설정 오류 탐지 결과의 정확도(정탐/오탐 여부)를 평가한다. 수집된 데이터를 바탕으로 서비스를 반복 개선하며, 주요 사용자 인터뷰를 통해 UX 개선 방향을 도출한다.

3. UI/UX 및 디자인 수행 방식: Figma와 AI Agent를 적극 활용해 와이어프레임 및 프로토타입을 제작한다. 본 서비스의 핵심 화면은 웹 브라우저 기반 AI 스마트 에디터와 세계관 관리 대시보드이며, 그래프 시각화 및 충돌 오류 리포트 UI가 작가에게 직관적으로 전달될 수 있도록 인터페이스 설계에 집중한다. 베타 테스팅 피드백을 반영해 UI를 반복 개선한다.

4. 기능 구현을 위한 주요 기술 습득 및 노력: GraphRAG 기반 지식 그래프 구축을 위한 Graph DB(Neo4j 등) Cypher 쿼리 설계와 LangGraph를 활용한 LLM 에이전트 프롬프트 엔지니어링을 집중 학습한다. Naive RAG와 GraphRAG 조합 방식을 연구하고, Elasticsearch와 Vector DB를 연계한 하이브리드 검색 전략을 실험한다. Kafka 기반 EDA 설계 역량을 쌓아 Ripple Effect 역추적 파이프라인을 안정적으로 구현하며, PoC를 통해 LLM 텍스트 → Graph DB 변환 및 RAG retrieval 핵심 로직의 기술적 실현 가능성을 선검증한 뒤 본 개발에 진입한다.
