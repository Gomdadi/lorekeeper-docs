## 상세 내용

### 기획

- 서비스가 해결할 문제와 대상 사용자를 정의하고, 전체 개발 일정 수립 `5월`

### 분석

- 경쟁 서비스의 기능·UX·BM을 비교 분석해 차별화 요소와 개발 우선순위를 결정하고, 팀 내 협업 방식 합의 `5~6월`

### 설계

- 서비스 전체 구조와 서버 환경을 설계하고, 자동 배포·운영·코드 관리 기준 확정 `6월`

### 디자인

- 화면 레이아웃 초안과 동작 가능한 시제품 제작 `6월`

### 개발

- 원고를 AI가 분석해 설정 충돌을 감지하는 핵심 기능 동작 여부 검증 (PoC) `6~7월`
- 핵심 기능을 순차적으로 개발해 1차 배포 목표 달성 `7~9월`
- 베타 테스팅 피드백을 바탕으로 기능 개선 및 서비스 품질 향상 `9~11월`

### 테스트

- 테스트 기준을 수립하고, 개발 전 과정에 걸쳐 단위 기능·통합 동작 검증 `6~11월`
- 배포 전 실제 사용자 흐름을 시나리오대로 전체 점검 `9월, 10월`

### 완성

- 베타 테스터에게 먼저 공개해 실제 반응과 피드백 수집 (1차 배포) `9월`
- 피드백을 반영한 최종 버전 정식 출시 (2차 배포) `10월`
