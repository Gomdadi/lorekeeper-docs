## 상세 내용

### 기획

- 핵심 문제와 타겟 사용자 정의 및 서비스 방향성·핵심 가치 구체화
- 단계별 완료 기준·목표 산출물 명시를 포함한 전체 프로젝트 마일스톤 수립

### 분석

- 국내외 유사 서비스(소설 집필 툴, 세계관 관리 툴 등) 기능·UX·BM 비교 분석
- 경쟁사 분석 결과 기반 본 서비스 핵심 차별점(설정 충돌 사전 감지, Ripple Effect 역추적 등) 도출
- 차별화 요소 실현을 위한 핵심 기능 목록 정의 및 구현 우선순위·기술 접근 방식 결정
- 서비스 전체 기능을 User Story 형태로 작성한 Product Backlog 구성
- Sprint 주기, 데일리 스크럼 방식, 회고 방법 등 팀 Agile 프로세스 합의 및 정립

### 디자인

- Figma 등 디자인 툴과 AI Agent를 활용한 UI/UX 와이어프레임 및 프로토타입 제작

### 설계

- Knowledge Graph, RAG 파이프라인, EDA 기반 Ripple Effect 역추적 등 핵심 기술 요소를 반영한 전체 시스템 아키텍처 설계
- AWS 기반 클라우드 인프라 구성 및 Terraform IaC·Kubernetes 오케스트레이션 전략 수립
- CI/CD 파이프라인(Github Actions 등) 및 무중단 배포 방식(Blue/Green 또는 Rolling) 설계
- 로깅·메트릭 수집·알림 체계 등 Observability 기반 운영·모니터링 전략 수립
- Git Branch 전략(Git Flow 등), 코드 리뷰 프로세스, 커밋 컨벤션 등 형상관리 기준 확정

### 개발

- LLM 텍스트 → 그래프 DB 변환 및 RAG 기반 설정 충돌 retrieval 핵심 로직 기술 검증 (PoC)
- MVP feature.md 기준 핵심 기능의 Sprint 단위 구현 및 1차 배포 목표 달성
- 베타 테스팅 피드백 반영을 통한 기능 고도화 및 서비스 품질 개선

### 테스트

- 서비스 특성에 맞는 테스트 범위·도구·커버리지 목표 정의 및 팀 내 테스팅 기준 수립
- 모듈·함수 단위 Unit Test 작성 및 CI 자동 실행 연동 (전 개발 과정 적용)
- 모듈 통합 시점의 컴포넌트 간 인터페이스·데이터 흐름 Integration Test 수행
- 1차·2차 배포 전 실제 사용자 시나리오 기반 E2E 테스트를 통한 서비스 전체 흐름 검증

### 완성

- MVP 완료 후 제한된 사용자 대상 베타 배포 및 실사용 피드백 수집 (1차 배포)
- 베타 테스팅 결과 반영 최종 버전의 정식 배포 및 서비스 운영 체계 가동 (2차 배포)
